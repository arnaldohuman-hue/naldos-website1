PHOTO PLACEHOLDERS:

hero.jpg

If a photo is missing, the page will show a plain placeholder area. Use JPG or WebP photos, ideally landscape orientation. Keep file sizes reasonable for faster mobile loading.

FREE PUBLISHING OPTION:
1. Create/sign in to a GitHub account.
2. Create a new public repository, for example: naldos-website.
3. Upload index.html and the images folder with your photos.
4. Open repository Settings -> Pages.
5. Select Deploy from a branch, choose main and /(root), then Save.
6. GitHub will provide a public website URL. Publishing settings can change; follow the instructions shown in GitHub Pages if the menu differs.
